How it works

Five agents live on Bud Street, each working a different building. Add a ticker on the Watch tab and the commune scores it on momentum, sentiment, value and safety, then votes a signal. Add a free key on the Key tab to swap in real prices.

How the commune thinks

Each ticker gets four scores — momentum, sentiment, value and safety — generated from its letters so a stock always reads consistently, then drifting a little to feel alive. A weighted vote turns them into Buy, Hold or Sell.
Bud Street is a game. Agent signals are simulated and not financial advice.
